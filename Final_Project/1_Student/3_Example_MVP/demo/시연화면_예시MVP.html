채점 콘솔 (보조) → 단독판 → run: —
입력 파일(.md · .txt — 형식 자유, 접수 에이전트가 읽는다)을 여기에 끌어다 놓아도 된다 — 올린 파일 없음 · 제출본 IPS 그대로
돌발 과제 .md · .txt (형식 자유)를 끌어다 놓아도 된다 — 선택된 파일 없음

① 진행 단계

    끝난 단계를 누르면 그 단계의 파일이 열린다

    ② 근거 파일

    분기를 고르고 ▶ 라이브 실행을 누른다 — 예시 MVP 엔진이 그 분기를 임시 복사본에서 다시 계산한다.
▷ 제출본 재생은 다시 계산하지 않고 제출된 runs/ 파일을 그대로 보여 준다.
입력 파일(IPS 변경)과 돌발 과제 md를 올리면 그 내용을 반영해 계산한다. 제출 폴더는 바뀌지 않는다.

    화면은 엔진이 남긴 runs/{분기}/ 파일을 그대로 읽어 보여 준다 — 화면은 계산하지 않는다

    ③ 결과 요약

    아직 결과가 없다

    ⇄ 실행 비교

    실행을 두 번 이상 하면 비교할 수 있다
