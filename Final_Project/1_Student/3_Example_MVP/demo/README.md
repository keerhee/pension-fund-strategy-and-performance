# 시연 예시 — 자율주행 시연 프로세스가 중심이다

예시 MVP 폴더에는 시연 방식이 세 가지 있다. **발표는 ① 시연 화면으로 한다.** ②는 채점자가 쓰는 보조 화면이고, ③은 파이썬 없이 흐름만 익히는 연습판이다.

| | 무엇 | 여는 법 | 엔진 |
|---|---|---|---|
| **① 시연 화면 (중심)** | 자율주행 시연 프로세스 — 단계 진행 · 근거 파일 · 사람 CIO 승인 · 1쪽 보고서 · 실행 비교 · 입력/돌발 md 올리기 | `start.command`(맥) · `start.bat`(윈도) → 첫 화면 — 화면 파일은 `demo/시연화면_예시MVP.html` | **예시 MVP** — 그 분기를 임시 복사본에서 다시 계산 (`sdp/demo.py`) |
| ② 채점 콘솔 (보조) | 개요 · 분기 보기 · 공개 점검 T1~T8 · 라이브 점검 L1~L3 · 문서 | ①의 오른쪽 위 「채점 콘솔 (보조) →」 또는 `/console` | 예시 MVP |
| ③ 단독판 (연습) | ①과 같은 흐름을 파일 하나로 — 장난감 엔진(자산군 6개 · 위원 4명) | `standalone/SDAM_시연화면_단독판.html` 더블클릭 (파이썬 불필요) | 화면 안의 예시 엔진 |

## ① 시연 화면 — 한 번의 시연 순서

1. 분기를 고르고 **▶ 라이브 실행** — 엔진이 매크로 → CMA → 리서치 → 배분안 6개 → IPS 적격 심사 → CRO → 상호 검토·투표 → IC 보고서까지 계산한다.
2. **⑨ 사람 CIO 결정**에서 멈춘다 — IC 보고서를 읽고 ✓ 승인 또는 ✕ 반려, 사유를 적는다. 엔진이 그 결정으로 마저 진행한다(보유 확정 · 변경 제안 처리 · 메타 리뷰).
3. 끝나면 **📄 1쪽 보고서**가 뜬다 — IC 보고서 · CIO 결정 · `data/cio_decisions.csv`에 적을 행.
4. **입력 파일**(IPS 변경)이나 **돌발 과제 md**를 올리고 다시 실행 → **⇄ 두 실행 비교**. 형식이 자유로운 메모·메일도 된다 — **접수 에이전트**(`sdp/intake.py`)가 표준 형식으로 옮겨 보여 주고, 사람이 ✓ 해석 확인을 눌러야 입력이 된다.
5. **▷ 제출본 재생**은 다시 계산하지 않고 제출된 `runs/` 파일을 그대로 보여 준다.

모든 실행은 임시 복사본에서 돈다. 제출 폴더의 파일은 바뀌지 않는다.

## 올리는 md 예시 — `3_Example_MVP/올릴파일/`

입력은 표준 형식 md와 자유 형식(메모 · 메일 · `.txt`) 둘 다 된다. 쓰는 법과 읽는 항목은 **[`올릴파일/README.md`](../올릴파일/README.md)** 의 입력 가이드를 본다. 아래는 표준 형식 예시이고, 같은 폴더에 자유 형식 예시 2개(`[입력-자유형식]` · `[돌발-자유형식]`)가 더 있다.

| 파일 | 넣는 곳 | 내용 | 예시 MVP에서 일어나는 일 |
|---|---|---|---|
| `[입력] 2024-02_유효종목수하한_3.5.md` | 📥 입력 파일 | 기준 분기 2024-02 · 유효 종목 수 하한 4.0 → 3.5 | 기각됐던 최대 샤프·적대적 분산자가 적격 → 권고 ERC → 동일가중 |
| `[돌발A] IPS변경_변동성상한_10→8.md` | 📄 돌발 과제 | 변동성 상한 10% → 8% | 배분안들이 새 한도 안에서 다시 만들어진다 — 기각이 늘지 않는 이유를 설명할 거리 |
| `[돌발B] 시장충격_주식-15_금리+150bp.md` | 📄 돌발 과제 | 다음 달 주식 −15% · 금리 +150bp · 금 +3% · 원자재 −5% | 가상의 2025-08을 붙여 새 분기를 결정 → 권고 최소분산 → 사람 CIO 결정 |
| `[돌발C] 모델교체_llm-y.md` | 📄 돌발 과제 | 판단 모델 교체 | 숫자는 코드가 계산하므로 제출본과 같은 결론이어야 한다 |

입력 파일이 읽는 항목: 변동성 상한(%) · 종목 상한/하한(%) · 유효 종목 수 하한 · 주식/채권/대체 하한·상한(%).
돌발 유형: `IPS 변경` · `시장 충격`(주식 한 달 수익률 · 금리 변화(bp) · 금 · 원자재) · `모델 교체`.

③ 단독판의 md 예시는 `standalone/` 안에 따로 있다(장난감 엔진의 형식).

## 팀 프로젝트로 넓히기

팀은 ①의 흐름(단계 · 근거 파일 · 사람 승인 · 보고서 · 비교)을 그대로 두고 **뒤의 엔진을 자기 시스템으로 바꾼다.** 화면이 부르는 곳은 `/api/demo/start` · `/api/demo/decide` · `/api/demo/replay` 세 곳뿐이다.
