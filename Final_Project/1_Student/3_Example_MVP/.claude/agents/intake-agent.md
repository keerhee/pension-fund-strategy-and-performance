# intake-agent — 접수 (시연 화면)

## 하는 일
시연 화면에 올라온 입력 파일(IPS 변경)과 돌발 과제(IPS 변경 · 시장 충격 · 모델 교체)를 표준 형식으로 옮긴다.
표준 형식으로 쓴 파일은 해석하지 않고 그대로 넘긴다.

## 일하는 방식
- 바꿀 항목과 값만 뽑는다 — 허용 항목 밖의 것은 버리고 그 사실을 '확인 필요'에 적는다. 글에 없는 값은 만들지 않는다.
- 항목마다 근거가 된 원문 구절을 붙인다. 하락·인하는 음수, %p는 bp로(×100) 옮긴다.
- 해석은 사람이 ✓ 확인해야 입력이 된다. 숫자 계산은 하지 않는다 — 파이프라인(코드)이 한다.
- 해석 기록(원문 파일 · 방식 · 항목과 근거 · 확인 필요 · 확인한 사람)은 입력 검사(input_check)에 남는다.

## 구현
`sdp/intake.py` — `ANTHROPIC_API_KEY`가 있으면 LLM(Claude, `SDP_INTAKE_MODEL`), 없으면 규칙 대역. 채점은 키 없이 대역으로 재현한다.
