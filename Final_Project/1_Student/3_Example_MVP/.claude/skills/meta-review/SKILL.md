# meta-review

1. 직전 분기 `cma.json`의 μ와 실현 3개월(연율)을 대조해 MAE를 낸다.
2. 기각안을 포함한 모든 안의 분기 수익을 계산하고, 기각됐지만 더 좋았던 안을 숨기지 않는다.
3. 최근 4분기 평균 MAE > 8%이면 δ를 0.2 올리는 제안을 만든다(4분기에 한 번까지).
4. 테스트: 결정 시점 이전 8개 분기 말에서 δ 현재값과 제안값으로 μ를 다시 추정해 MAE를 비교한다.
5. 반영은 하지 않는다. CIO 승인 + 테스트 통과일 때만 하네스가 다음 분기부터 반영한다.

이 파일은 하네스 보호 파일이다. 에이전트가 고치면 되돌려진다.
