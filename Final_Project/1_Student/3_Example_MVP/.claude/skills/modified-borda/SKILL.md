# modified-borda

1. 각 PC 에이전트는 자기를 뺀 적격안을 자기 렌즈로 순위 매긴다.
2. 상위 4개에 5·4·3·2점, 최하위 1개에 −2점(적격안이 5개 이하일 때의 사전 등록 규칙).
3. $\hat S$는 득표의 최소-최대 정규화, $M$은 정량 점수 5개(최근 36개월 샤프·IPS 여유·유효 종목 수·국면 적합·추정 위험)의 정규화 평균.
4. $\text{Score}=\lambda\hat S+(1-\lambda)M$, λ=0.5.
5. 검산: 과제 문서 §5 M8 예제 → (0.473, 0.850, 0.900, 0.450), 채택 C (점검 T5).

이 파일은 하네스 보호 파일이다. 에이전트가 고치면 되돌려진다.
