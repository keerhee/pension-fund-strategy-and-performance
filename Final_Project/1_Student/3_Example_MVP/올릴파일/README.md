# 올릴파일 — 시연 화면 입력 가이드

`start.command`로 연 **시연 화면**에 올리는 파일이다. 올리는 칸은 두 개다.

| 칸 (시연 화면 버튼) | 무엇을 올리나 | 올린 뒤 누를 버튼 |
|---|---|---|
| **📥 입력 파일 올리기** | IPS를 바꿔 다시 계산할 때 — 어느 분기를, 어떤 IPS로 | ▶ 라이브 실행 |
| **📄 돌발 과제 md 올리기** | 발표 당일 받은 돌발 과제 — IPS 변경 · 시장 충격 · 모델 교체 | ◆ 돌발 과제 투입 |

둘 다 올리면 입력(IPS 변경)이 먼저 적용되고 그 위에 돌발이 겹친다 — 이때는 ◆ 돌발 과제 투입을 누른다.

---

## 형식은 두 가지 다 된다

| | 표준 형식 | 자유 형식 |
|---|---|---|
| 모양 | 정해진 줄(`기준 분기:` · `유형:` · `- 항목: 값`) | 메모 · 메일 · 문장 — 아무렇게나 |
| 파일 | `.md` | `.md` · `.txt` |
| 처리 | 해석 없이 **그대로** 엔진에 들어간다 | **접수 에이전트**가 표준 형식으로 옮겨 보여 준다 → 사람이 **✓ 해석 확인**을 눌러야 들어간다 |
| 예시 | `[입력]` · `[돌발A]` · `[돌발B]` · `[돌발C]` | `[입력-자유형식]` · `[돌발-자유형식]` |
| 언제 쓰나 | 결과를 정확히 재현해야 할 때 · 채점 | 받은 메모·메일을 그대로 시연할 때 |

어느 형식이든 **엔진이 읽는 항목은 같다**(아래 표). 그 밖의 내용은 쓰지 않는다 — 자유 형식이면 접수 에이전트가 '확인 필요'로 알려 준다.

### 엔진이 읽는 항목

| 구분 | 항목 | 값 |
|---|---|---|
| 입력 · 돌발(IPS 변경) | 기준 분기 | `2024-02`처럼 — 2022-08부터 3개월 간격 (입력 파일만) |
| | 변동성 상한 · 종목 상한 · 종목 하한 | % |
| | 유효 종목 수 하한 | 숫자 (예: 3.5) |
| | 주식 · 채권 · 대체 하한/상한 | % |
| 돌발(시장 충격) | 주식 한 달 수익률 · 금 · 원자재 | % (하락은 음수) |
| | 금리 변화 | bp (1.5%p = 150bp) |
| 돌발(모델 교체) | 판단 모델 | 이름 |
| 돌발(결함 주입) — 채점용 | 주입 배분안 · 리서치 메모 추가 | `SPY 50, EFA 10, …`(%) · 문장 |
| 공개 점검 — 채점용 | 점검 · 분기 | `T1`~`T8` 또는 `전체` · `2024-11` (T7·T8) |

## 1. 표준 형식 — 이렇게 쓴다

**입력 파일**

```markdown
# 입력 파일 — 제목은 자유
기준 분기: 2024-02

## IPS 변경
- 유효 종목 수 하한: 3.5
- 변동성 상한: 9%
```

**돌발 과제** — `유형:`은 `IPS 변경` · `시장 충격` · `모델 교체` 중 하나

```markdown
# 돌발 과제 B — 다음 달 시장 충격
유형: 시장 충격

## 변경 내용
- 주식 한 달 수익률: -15%
- 금리 변화: +150bp
- 금: 3%
- 원자재: -5%
```

- 바뀌는 값은 `10% → 8%`처럼 적어도 된다 — 마지막 숫자를 새 값으로 읽는다.
- 적지 않은 항목은 제출본 IPS 그대로다. 표의 항목 이름을 그대로 쓴다.
- 표준 형식인데 틀린 곳이 있으면(모르는 항목 이름 등) 접수 에이전트가 자유 형식처럼 다시 읽어 보여 주고 확인을 받는다. 그래도 값이 맞지 않으면(없는 분기 등) ◇ 입력 검사에서 멈추고 사유를 보여 준다 — 엔진은 오류가 있는 입력으로 계산하지 않는다.

## 2. 자유 형식 — 이렇게 쓰면 잘 읽힌다

```text
2024년 2월 회의 안건입니다. 유효 종목 수 기준을 4.0에서 3.5로 낮춰서 다시 돌려 봅시다.
다음 달 증시가 15% 급락하고 금리는 1.5%p 오르는 시나리오도 봐 주세요.
```

- **숫자와 방향을 함께** 적는다 — 「15% 급락」 「1.5%p 오르는」 「3%로 낮춰」. 하락·인하·내린다는 음수로 읽는다.
- **분기는** `2024-02` 또는 「2024년 2월」.
- **한 문장(또는 「…하고」로 이은 구절)에 한 항목**이 가장 정확하다.
- 엔진이 읽지 않는 말(예: 신용 스프레드 · 환율)은 무시하고 '확인 필요'에 적는다. 값 없이 언급만 한 항목도 알려 준다.
- 입력 칸에 시장 충격을 올리면 「돌발 과제 칸에 올려야 한다」며 확인을 막는다.

### 접수 에이전트가 보여 주는 것 — 확인하고 누른다

```text
접수 에이전트 해석 — [돌발-자유형식] 긴급 시황 메일.txt
방식: 규칙 대역 (키 없음 — 정해진 낱말·숫자 규칙)
유형: 시장 충격

[바꿀 항목 ← 근거가 된 원문]
- 주식 한 달 수익률 = -15%   ← “다음 달 증시가 15% 급락하고”
- 금리 변화 = +150bp   ← “금리는 1.5%p 오르는 시나리오를 돌려 봐 주십시오.”
...
[확인 필요]
- 엔진이 읽지 않는 항목이 있다(무시함): “신용 스프레드도 넓어질 수 있으나 …”

[엔진에 넘길 표준 형식]
...
```

해석이 틀렸으면 확인하지 말고 원문을 고치거나 표준 형식으로 다시 올린다. 확인한 해석은 원문 파일 · 방식 · 항목과 근거 · 확인 필요 · 확인한 사람과 함께 ◇ 입력 검사(`input_check`)와 개입 기록에 남는다.

**해석 방식.** `ANTHROPIC_API_KEY`가 있으면 Claude(LLM)가, 없으면 규칙 대역이 해석한다. 채점은 키 없이 대역으로 재현한다 — 같은 원문이면 같은 해석이 나온다. LLM 호출이 실패하면 대역으로 내려가고 그 사실이 '방식'에 적힌다.

## 이 폴더의 예시

| 표시 | 파일 | 형식 | 넣는 칸 | 내용 |
|---|---|---|---|---|
| **[입력]** | `[입력] 2024-02_유효종목수하한_3.5.md` | 표준 | 📥 입력 | 2024-02 · 유효 종목 수 하한 4.0 → 3.5 |
| **[돌발A]** | `[돌발A] IPS변경_변동성상한_10→8.md` | 표준 | 📄 돌발 | IPS 변경 — 변동성 상한 10% → 8% |
| **[돌발B]** | `[돌발B] 시장충격_주식-15_금리+150bp.md` | 표준 | 📄 돌발 | 주식 −15% · 금리 +150bp · 금 +3% · 원자재 −5% |
| **[돌발C]** | `[돌발C] 모델교체_llm-y.md` | 표준 | 📄 돌발 | 판단 모델 교체 |
| **[입력-자유형식]** | `[입력-자유형식] 투자위원회 메모_분산요건 완화.md` | 자유 | 📥 입력 → ✓ 해석 확인 | 회의 메모 → 2024-02 · 유효 종목 수 하한 3.5 · 대체 상한 25% |
| **[돌발-자유형식]** | `[돌발-자유형식] 긴급 시황 메일.txt` | 자유 | 📄 돌발 → ✓ 해석 확인 | 메일 → 주식 −15% · 금리 +150bp · 금 +3% · 원자재 −5% (신용 스프레드는 확인 필요) |

시연 화면의 「입력 예시 내려받기 / 돌발 예시 내려받기」에서도 같은 파일을 받을 수 있다.
파이썬 없이 쓰는 단독판(연습)의 md는 형식이 달라 `demo/standalone/`에 따로 있다.
