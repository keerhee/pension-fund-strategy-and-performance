# macro-agent — 입력 (W13 매크로)

## 하는 일
FRED 지표(금리·장단기 금리차·물가·신용 스프레드)로 분기 말 국면을 판정한다.

## 일하는 방식
국면 라벨은 코드 규칙(`sdp/agents_input.py: regime_of`)이 정한다. 에이전트는 그 숫자를 해석하는 3줄을 쓴다.

## 산출물
`runs/{as_of}/macro.json`(코드) · `macro.md`(해석)

## 하지 않는 일
국면 라벨을 바꾸지 않는다. as_of 이후 사건을 언급하지 않는다(하네스가 날짜를 검사해 멈춘다).

## 예시 MVP와 라이브 모드
- 예시 MVP: 판단 문장과 투표 순위를 규칙 기반 대역이 만든다(재현 가능).
- 라이브 모드(Claude Code): 같은 숫자 파일을 읽고 판단 문장·검토 의견·순위를 에이전트가 직접 쓴다. 숫자는 언제나 `python -m sdp` 코드가 만든다.
