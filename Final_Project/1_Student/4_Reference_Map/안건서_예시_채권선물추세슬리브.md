## 1. 한 줄 요약

국채선물 추세 신호 하나로 움직이는 슬리브를 비중 상한 2% 안에서 편입하자는 안건입니다.
교차 자산 검증을 통과했고, 기존 주식 중심 배분과 상관이 낮아 위기 구간의 손실을 줄이는 쪽으로 작동할 것으로 봅니다.

## 2. 제안 내용

| 항목 | 내용 |
|---|---|
| 무엇을 | 국채선물(3년·10년) 추세추종 슬리브 1개 |
| 얼마나 | 전체 기금 대비 **최대 2%**, 처음 3개월은 1%로 시작 |
| 어디서 줄이나 | 채권 블록 안에서 같은 금액을 줄임 — 주식·대체 비중은 그대로 |
| 언제 | 의결 다음 달 첫 리밸런싱일 |
| 어떻게 멈추나 | 슬리브 손실이 기금 대비 −0.3%에 닿거나, 메타 리뷰어가 알파 소멸을 표시하면 자동으로 0%로 되돌림 |

## 6. 예상 반대 의견과 답

IC 회의실에서 ic-critic이 네 관점으로 표결하며 반대 의견을 붙입니다. 미리 예상되는 반대 의견과 답을 적어 둡니다.

| 예상 반대 의견 | 답 |
|---|---|
| 검증 기간의 대부분이 금리 하락기라 결과가 한쪽으로 치우쳤다 | 2022~2023 금리 상승기 성과를 따로 첨부. 6개월 재심에서 다시 확인 |
| 2%로는 기금 전체에 의미 있는 효과가 없다 | 첫 편입은 효과보다 운영 검증이 목적. 재심 때 상한 조정 여부를 별도 안건으로 |
| 추세 신호는 이미 많이 알려져 알파가 줄고 있다 | 메타 리뷰어가 실현 성과를 추적해 소멸이 보이면 자동 정지·퇴출 |
