# 기말 팀 프로젝트 (Final Project) — 우리 기금의 자율주행 포트폴리오를 만들고 감독하라

BAF.60080 특강 XS(자율주행 포트폴리오)와 짝을 이루는 기말 팀 프로젝트다. 기금 하나의 투자정책서(IPS)를 정하고, 그 안에서
자본시장 가정 → 배분안 경쟁 → 리스크 심사 → 상호 검토 · 표결 → 투자위원회(IC) 보고 → 사후 학습까지 **에이전트들이 스스로
돌리는 운용 시스템**을 만든다. 사람은 CIO 한 명만 남아 IC 보고서를 받고 결정한다.

## 시작하기

1. `1_Student/1_Project_Guide.pdf`(과제문)를 먼저 읽는다.
2. `1_Student/2_Example_MVP/start.command`(맥) 또는 `start.bat`(윈도)를 더블클릭해 채점 콘솔을 연다. 파이썬 3.10 이상이 필요하다.
3. 채점 콘솔에서 **공개 점검 → [T1~T8 전체 실행]**을 눌러 본다. 제출물도 채점자가 이렇게 돌린다.

관련 자료: [`특강/특강I_자율주행포트폴리오/`](../특강/특강I_자율주행포트폴리오) (Ang · Azimbayev · Kim 2026), 보충교재 `13_자율주행자산운용/`.

## 기억할 다섯 문장

1. 계산은 코드, 판단은 에이전트, 결정은 사람.
2. 채점자는 더블클릭 한 번으로 여러분의 시스템을 다시 돌린다.
3. 예시와 달라진 점이 점수다.
4. 규칙은 결과를 보기 전에 정한다. 바꾸면 기록한다.
5. 불리한 결과를 숨기면 감점이다.
