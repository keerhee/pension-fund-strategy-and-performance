# 보충교재

16주 과정 밖에서 읽는 자료다. 본 과정 덱과 달리 **한 주제를 끝까지 따라가는 단독 덱**이고,
케이스도 실습데이터도 붙지 않는다. 특정 주차를 더 파고들고 싶을 때, 또는 학기 시작 전에 감을 잡고 싶을 때 꺼내 본다.

**폴더 번호는 강의 진도 순서다** (2026-10-15 재편). 01부터 차례로 그 주차 강의본을 본 뒤에 열면 된다.
주제가 같은 폴더는 하나로 합쳤고, 합친 폴더 안에는 원래 묶음을 하위 폴더로 남겼다.

## 09_위험관리와적극적운용 — W09 위험관리와성과평가

**VaR와미달손실확률** — 리스크 측정의 기본 개념을 다섯 단계로 쌓는다. 가치 · 수익률 · 손실의 세 눈금 → VaR의 정의(손실분포의 분위수) → 신뢰수준 $1-\alpha$와 꼬리확률 $\alpha$의 표기 차이 → 정규분포 VaR 계산(100억 원 포트폴리오의 99% 일간 VaR 약 4.6억 원, 제곱근 규칙과 그 전제) → 미달손실확률(목표 하한을 정하고 확률을 묻는다). VaR은 확률을 고정해 금액을 묻고, 미달손실확률은 하한을 고정해 확률을 묻는다 — 같은 꼬리를 두 방향에서 읽는다. W06 GBI의 손실확률 조건과 W07 TDF 손실확률 식을 읽을 때도 바탕이 된다.
