# W5 IC 케이스 데이터 사전 (기준일 2026-09-09)

케이스 문서·덱·이 데이터만으로 심의가 끝나도록 만든 교육용 데이터셋이다. 공시 수치와 교육용 가정은 모든 표에서 `is_assumed` 열(0 = 공시·의결 수치, 1 = 교육용 가정)로 구분한다. 교육용 가정은 학생이 `w5_build.py`에서 바꾸어 판정 결과가 어떻게 달라지는지 확인하는 것이 실습의 일부다.

## 실행 순서

```
python w5_build.py      # CSV 12개 생성
python w5_compute.py    # 판정 조건 ①~⑤(제1호, 기금위) · 조건 ①~③(제2호, KIC) 계산 → w5_results.json, compute_log.txt
```

필요 패키지: numpy, pandas, scipy. 실제 수익률 패널로 부트스트랩을 하려면 아래 코드로 내려받아 `fml_w5_panel_sim.csv` 대신 넣는다(열 이름 규약 동일). 보너스 안건의 주식·채권 롤링 상관도 같은 데이터로 계산한다.

```
import yfinance as yf
px = yf.download(["EWY","URTH","IEF","BNDX","VNQ"], start="2016-09-01", interval="1mo")["Close"]
ret = px.pct_change().dropna()
ret.columns = ["eq_kr_ret","eq_gl_ret","bond_kr_ret","bond_gl_ret","alt_ret"]   # ETF 프록시(국내채권은 IEF로 대용)
ret.index.name = "date"; ret.to_csv("fml_w5_panel.csv")
# 보너스 — 36개월 롤링 주식·채권 상관
ret["eq_gl_ret"].rolling(36).corr(ret["bond_gl_ret"]).dropna().to_csv("fml_w5_rolling_corr.csv")
```

### fml_w5_cma.csv · fml_w5_corr.csv · fml_w5_corr_2022.csv — 6자산 CMA와 상관(교육용 가정)

| 열 | 정의 | 단위 |
|---|---|---|
| mu · sigma | 5년 기대수익 · 변동성(연율) | 소수 |

CMA와 정상 체제 상관은 W4 케이스 데이터와 같다(W2 패널 → W4 공분산 → W5 ERC·HRP 재사용). `fml_w5_corr_2022.csv`는 주식·채권 상관이 +0.5로 뒤집힌 2022형 체제(강의 3교시의 "정상기 −0.2 → 2022 +0.5"를 자산군 수준으로 옮긴 교육용 가정)다. 조건 ③의 CVaR과 σ22는 이 행렬로 계산한다.

### fml_w5_kic_factor.csv · fml_w5_kic_factor_sigma.csv · fml_w5_kic_factor_corr.csv · fml_w5_kic_corr.csv · fml_w5_kic_views.csv — KIC 5자산 · 4팩터

|---|---|---|

팩터 적재·팩터 σ·팩터 상관은 교육용 가정이다. 자산 상관(`fml_w5_kic_corr.csv`)과 뷰 시트(`fml_w5_kic_views.csv`)는 W4 제1호와 같다. 팩터 위험기여는 e = Bᵀw, RC_k = e_k(Fe)_k / eᵀFe 로 계산한다.

### fml_w5_panel_sim.csv — 모의 월간 수익률 패널

`date`(월말) · `<asset>_ret`(월간 단순수익률, 소수) · `rf`. CMA와 정상 상관에서 생성한 120개월 정규 난수(seed 60080)로 HRP 부트스트랩(조건 ⑤) 전용이다. 실제 수익률이 아니다.

## 판정 조건과 계산 대응

| 조건 | 계산 | 스크립트 위치 |
|---|---|---|
| 조건 ① 위험 집중 | 현행 SAA의 주식 위험기여 RC_eq = Σ_{i∈주식} w_i(Σw)_i / wᵀΣw. 기준선 75% 초과 여부 | [제1호] 조건 ① |
| 조건 ② 기대수익 | 후보 배분의 μ ≥ 5.5%. 후보 = 주식 RC 상한 c(90 … 40%)별 max μ 배분(제도 제약 포함) · ERC · HRP | [제1호] 조건 ② |
| 조건 ③ 위험한도 | CVaR95 = μ − 2.06σ ≥ −15% — 정상 상관과 2022형 상관 모두 | [제1호] 조건 ③ |
| 조건 ④ 2022형 스트레스 | 후보의 2022형 수익률(시나리오 B) ≥ 현행 SAA(−9.42%) | [제1호] 조건 ④ |
| 조건 ⑤ HRP 안정성 | linkage 4종의 주식 RC 범위, 모의 패널 부트스트랩 300회의 5·50·95% | [제1호] 조건 ⑤ |
| 조건 ① 팩터 집중 | 현행 KIC의 팩터 위험기여 최대값 > 상한 후보 60% | [제2호] 조건 ① |
| 조건 ② 기대수익 비용 | 팩터 상한 c(80 … 50%)별 max π 배분의 Δμ ≥ −0.5%p 인 가장 낮은 상한. 팩터 ERC(제약)도 함께 | [제2호] 조건 ② |
| 조건 ③ 뷰의 양립 | W4 뷰 시트(자신감 ≤ 20%, TE ≤ 1%)의 틸트를 상한형 배분 위에 얹었을 때 성장 팩터 RC가 상한 + 밴드 안인가 | [제2호] 조건 ③ |
