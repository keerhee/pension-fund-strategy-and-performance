# W08 · 중간시험

강의는 없다. 8주차는 시험으로 비운다.

| 항목 | 내용 |
|---|---|
| 시점 | 8주차 |
| 범위 | **M1\~M9** — 1\~7주차에서 다룬 정규 모듈 9개 |
| 제외 | 특별세션 **SS2**(재균형 프리미엄)는 범위에서 뺀다 |
| 비중 | 25% (전체 평가 중)|
