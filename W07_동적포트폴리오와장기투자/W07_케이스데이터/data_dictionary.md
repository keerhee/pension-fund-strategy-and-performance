# W7 IC 케이스 데이터 사전 (기준일 2026-09-20)

케이스 문서·덱·이 데이터만으로 심의가 끝나도록 만든 교육용 데이터셋이다. 공시 수치와 교육용 가정은 모든 표에서 `is_assumed` 열(0 = 공시·의결·통계 수치, 1 = 교육용 가정)로 구분한다. 교육용 가정은 학생이 `w7m9_build.py` 상단 상수에서 바꾸어 판정 결과가 어떻게 달라지는지 확인하는 것이 실습의 일부다.

## 실행 순서

```
python w7m9_build.py      # CSV 8개 생성 (현금흐름 추계 · 글라이드패스 · KIC 모의 패널)
python w7m9_compute.py    # 제1호 조건 ①~⑤ · 제2호 조건 ①~③ 계산 → w7m9_results.json, compute_log.txt
```

필요 패키지: numpy, pandas. 실제 시계열로 제2호를 다시 돌리려면 아래처럼 받아 `fml_w7m9_kic_panel_sim.csv`와 같은 열 이름으로 넣는다(FRED 10년 금리 `DGS10`, 기대 인플레 `T10YIE`, `VIXCLS`; 자산은 ETF 프록시 TLT · TIP · URTH, 변동성 헤지는 VIXY).

```
import yfinance as yf, pandas_datareader.data as web
px = yf.download(["TLT","TIP","URTH","VIXY"], start="2011-01-01", interval="1mo")["Close"].pct_change()
st = web.DataReader(["DGS10","T10YIE","VIXCLS"], "fred", "2011-01-01").resample("ME").last()
```

### fml_w7m9_cma.csv — 두 자산군 CMA (교육용)

### fml_w7m9_kic_panel_sim.csv — KIC 제2호 월간 모의 패널 (교육용, 480개월)

| 열 | 정의 | 단위 |
|---|---|---|
| date | 월말 | YYYY-MM-DD |
| yield10 · infl_exp · vix | 상태변수 — 10년 금리 · 기대 인플레이션 · 변동성 지수 | % · % · pt |
| bond_long_ret · tips_ret · eq_ret · vol_hedge_ret | 장기 국채 · 물가연동채 · 주식 · 변동성 헤지 월간 수익률 | 소수 |

설계(데이터 생성 과정, `w7m9_build.py`의 `simulate_kic`): 상태변수의 **수준**이 다음 달 기대수익을, 상태변수의 **충격**이 이번 달 실현수익을 움직인다.

- 장기 국채 = 0.04 + 0.45 × (전월 금리 − 3.5) − 15 × 금리 충격 + 잡음 — 듀레이션 15. 금리가 떨어지면 지금 오르고, 이후 기대수익은 낮아진다
- 주식 = 0.45 − 1.2 × (전월 기대 인플레 − 2.2) + 0.04 × (전월 VIX − 18) − 2 × 인플레 충격 − 0.5 × VIX 변화 + 잡음 — 인플레가 높으면 이후 주식 기대수익이 낮다
- 물가연동채 = 0.02 + 6 × 인플레 충격 − 6 × 금리 충격 + 잡음 — 인플레 상승 충격에 오른다
- 변동성 헤지 = −0.5 + 0.9 × VIX 변화 + 잡음 — 평시 보유 비용(연 약 −6%), VIX 급등 시 이익

난수 시드는 71로 고정했고 결과에 맞춰 고르지 않았다. 같은 생성 과정의 다른 40년(시드 1~5)에서의 결과는 `compute_log.txt`의 강건성 점검에 있다. **이론의 작동 방식을 보여 주기 위한 교육용 자료이며 실제 시장의 증거가 아니다.**

## w7m9_compute.py 가 계산하는 것

- 제1호 조건 ① H/F(향후 30년 보험료 PV ÷ 기금)와 임계 0.625(총부 기준 위험자산 비중 40%) 도달 연도, 조건 ② 종점 비중 ≥ w_h, 조건 ③ 정점 이후 1σ 손실액 ÷ 급여 ≤ 1년치, 조건 ④ 소진 ≥ 2071, 조건 ⑤ 순유출 이후 안전자산 ≥ 급여 1.5년치. 참고 산수로 2008형 충격 1회(2027 · 순유출 전환 해 · 2050)가 소진을 앞당기는 연수와 안 B 의 속도·종점 민감도.
- 제2호: VAR(1)(상태변수 3 · 자산 4)을 추정해 4,000개 경로를 만들고, 1년 · 10년 지평의 CRRA(γ = 5) 최적 고정 비중을 찾는다. 수단별 조건 ① 상태변수 → 기금 자산의 이후 1년 초과수익 회귀 |t| ≥ 2(Newey–West), 조건 ② 헤징 수요(10년 − 1년 최적 비중) ≥ 3%p, 조건 ③ 그 수단을 뺀 최적 대비 10년 확실성등가 기여(비용 차감) > 1bp/년. 세 안(A · B · C)의 10년 확실성등가, γ 민감도(2 · 5 · 10), 시드 1~5 강건성. 참고로 간편 공식 (1 − 1/γ)·β·σ_x/σ_a(10년 회귀)의 값도 남긴다 — 공분산을 보지 않는 근사라 직접 계산과 크게 다르다. 임계값 ①②③은 교육용 가정이다.

결과는 `w7m9_results.json`(구조화)과 `compute_log.txt`(읽는 용)에 남는다.
