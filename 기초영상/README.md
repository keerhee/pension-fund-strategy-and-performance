강의 개념 하나를 6컷 · 9:16 · 30~45초 세로 웹툰 숏폼으로 푸는 **'연기금 IC 일기'** 시리즈다.

완성 mp4는 저장소에 올리지 않는다 — 여기에는 대본 · 렌더 스크립트 · 기획표만 둔다.
