## 01_PE기초영상 — PE 기초 웹툰 숏폼 'IC 일기' (W14 대체투자와비유동성과 함께)

부엉이 CIO와 펭귄 신입이 PE 개념 하나를 6컷 30초 세로(9:16) 웹툰 숏폼으로 푼다.
완성 영상(13편 · 각 32~43초)은 저장소 규칙상 mp4를 올리지 않아 원본 폴더의 `output/`에만 있다. 여기에는 에피소드 대본(`episodes/`)과 렌더 스크립트(`render/`), 그리고 Claude Code 하네스(에이전트 6종 + 스킬)가 들어 있고,
1화만 검수용 정지 컷이 있다. 사용법은 [`ic-webtoon-short/README.md`](01_PE%EA%B8%B0%EC%B4%88%EC%98%81%EC%83%81/ic-webtoon-short/README.md)에 있다.
