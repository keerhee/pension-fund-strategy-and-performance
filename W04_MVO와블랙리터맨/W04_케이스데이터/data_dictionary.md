# W4 IC 케이스 데이터 사전 (기준일 2026-09-09)

케이스 문서·덱·이 데이터만으로 심의가 끝나도록 만든 교육용 데이터셋이다. 공시 수치와 교육용 가정은 모든 표에서 `is_assumed` 열(0 = 공시·의결 수치, 1 = 교육용 가정)로 구분한다. 교육용 가정은 학생이 `w4_build.py`에서 바꾸어 판정 결과가 어떻게 달라지는지 확인하는 것이 실습의 일부다.

## 실행 순서

```
python w4_build.py      # CSV 8개 생성
python w4_compute.py    # 판정 조건 K1~K4(제1·2호, 기금위) · V1~V4(제1호, KIC) · N1(제2호, NPS) 계산
```

필요 패키지: numpy, pandas, scipy. 실제 ETF 패널을 쓰려면 아래 코드로 내려받아 `fml_w4_panel_sim.csv` 대신 넣는다(열 이름 규약 동일).

```
import yfinance as yf
px = yf.download(["URTH","EEM","IEF","LQD","VNQ","DBC"], start="2016-09-01", interval="1mo")["Close"]
ret = px.pct_change().dropna(); ret.columns = [f"{c}_ret" for c in ret.columns]
ret.index.name = "date"; ret.to_csv("fml_w4_panel.csv")
```

| 열 | 정의 | 단위 |
|---|---|---|
| asset | eq_gl·ust·ig·alt_pe·alt_infra | — |
| w_mkt | 시장(균형) 비중 0.50·0.20·0.15·0.10·0.05 | 소수 |

### fml_w4_panel_sim.csv — 모의 월간 수익률 패널

`date`(월말) · `<asset>_ret`(월간 단순수익률, 소수) · `rf`. CMA와 상관 행렬에서 생성한 120개월 정규 난수(seed 60080)로 부트스트랩·Ledoit-Wolf 실험 전용이다. 실제 수익률이 아니다.

## 판정 조건과 계산 대응

| 조건 | 계산 | 스크립트 위치 |

| K2 이행 실행 가능성 | 표류 경로 w_t = w_0((1 + r_p)/(1 + g))^t, 필요 순매도 = (표류 종점 − 후보) × 2031 총자산 / 5, 한도 = ADV × 참여율 × 거래일 | [M4] K2 |
