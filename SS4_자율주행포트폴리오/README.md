# SS4 — 자율주행 포트폴리오

Ang, A., Azimbayev, N., & Kim, A. (2026). *The Self Driving Portfolio: Agentic
Architecture for Institutional Asset Management* (arXiv:2604.02279)의 파이프라인을
**이 과정 16주 교재로 축소 구현한** 특별세션이다.

논문은 약 50개 에이전트가 자본시장 가정을 만들고 20가지 넘는 방법으로 포트폴리오를
구성해 서로 비평·표결하며, 메타 에이전트가 예측을 실현과 대조해 다른 에이전트의 코드와
프롬프트를 고쳐 쓰는 구조를 제시한다. 전체를 통제하는 것은 **투자정책서(IPS)** — 사람
운용역을 규율하던 바로 그 문서다.

## 구성

| 파일 | 내용 |
|---|---|
| `SS4_자율주행포트폴리오_강의본.pdf` | 38장 — 논문 구조 · 교재 매핑 · harness · MVP 실습 · 한계 |
| `SS4_케이스_자율파이프라인도입과규율_IC.pdf` | 19장 — 모의 투자위원회, 안건 2건 |
| `self-driving-mvp/` | 실제로 돌아가는 구현체 |
| `_build/` | 덱 생성 스크립트 (재빌드용) |

## 여섯 층과 우리 교재

| 층 | 하는 일 | 주차 |
|---|---|---|
| 거버넌스 | IPS가 전 과정을 제약 | W01 · W16 |
| 입력 | 자본시장 가정(CMA) | W03 |
| 구성 | 여러 방법이 경쟁 | W04 · W05 · W06 |
| 비평·투표 | 심사와 표결 | **16주 내내의 IC** |
| 탐색 | 새 방법 제안 | W13 · W14 (MVP에서는 생략) |
| 자기개선 | 예측 대 실현 대조 | W10 |

비평·투표 층이 이 세션의 열쇠다. **학생이 16주 동안 사람으로서 해온 IC가 논문에서
에이전트가 하는 일이다.** 새 이론을 배우는 세션이 아니라, 해온 일을 자동화하면 무엇이
남고 무엇이 사라지는지 확인하는 세션이다.

## MVP — 에이전트 7개

```
ips-guardian      거버넌스   IPS 해석과 위반 판정
cma-builder       입력       기대수익률·공분산 (W03)
alloc-mvo         구성       평균분산 최적화 (W04)
alloc-bl          구성       블랙리터맨 (W05)
alloc-riskparity  구성       위험기여 균등 (W06)
ic-critic         비평·투표   적격 심사와 네 관점 표결
meta-reviewer     자기개선   예측 대 실현 · 지시문 수정 제안 (W10)
```

구조는 [`revfactory/harness`](https://github.com/revfactory/harness)(황민호, Apache-2.0)로
세웠다. 도메인별 에이전트 팀을 설계하는 Claude Code 메타 스킬이며, 논문의 여섯 층과
개념이 1대 1로 대응한다 — 특히 harness의 Phase 7 "하네스 진화"가 논문의 메타 에이전트다.

## 실행 결과 (2026-08-22 · 본 강의 시뮬레이션)

자산 11개 · 학습 84개월 / 평가 35개월.

| 후보 | 유효N | IPS | 기대 | 실현 | MDD | 표결 |
|---|---|---|---|---|---|---|
| MVO (W04) | 3.93 | **위반** | 5.93% | **8.58%** | -5.0% | 자동 기각 |
| 블랙리터맨 (W05) | 5.53 | 적격 | 2.33% | 4.80% | -10.3% | 22.50 |
| 리스크 패리티 (W06) | 9.92 | 적격 | 5.25% | 7.43% | -7.6% | **35.96 채택** |

세 가지가 드러났다.

1. **MVO가 분산 요건(유효 종목 수 4.0)을 어겨 자동 기각됐다.** W04에서 가르치는 코너해가
   그대로 나왔고, 사람이 아니라 정책이 잡았다.
2. **그 기각된 안의 실현수익이 가장 높았다.** 규율을 지킨 대가가 1.15%p로 계산된다.
   이것이 IC 케이스의 안건이 된다.
3. **CMA는 크게 틀렸다** — 평균 절대오차 6.85%p, 금은 18.2%p. 그럼에도 성과가 나쁘지
   않았던 것은 예측이 맞아서가 아니라 제약이 분산을 강제했기 때문이다.

메타 에이전트는 지시문 수정 2건을 제안했고, IPS 7.4항(킬스위치)에 따라 **자동 반영되지
않았다**.

## 다시 돌리기

```bash
cd self-driving-mvp
python3 -m venv .venv && .venv/bin/pip install yfinance pandas numpy scipy
.venv/bin/python fetch_data.py
RUN=$(date +%Y-%m-%d)
for s in cma alloc_mvo alloc_bl alloc_rp ic_critic meta_review; do
  .venv/bin/python scripts/$s.py "$RUN"
done
```

산출물은 `self-driving-mvp/runs/{날짜}/`에 쌓인다. 데이터 기간이 달라지면 숫자는
달라진다 — 형식이 같으면 정상이다.

## 한계

CFA Institute는 이 구조에 다섯 가지를 지적했다(*Self-Driving Portfolio: Promise and
Pitfalls*, 2026): 연쇄 오류, 거짓 합의, 자기개선의 역설, 감사 가능성, 국면 민감성.
MVP는 앞의 넷에 부분적으로 대응했고 **마지막 하나는 대응하지 못했다** — 금 예측이
18.2%p 빗나간 것이 그 증거다.
