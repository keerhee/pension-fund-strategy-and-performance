# W7 M8 IC 케이스 데이터 사전 (기준일 2026-09-21)

케이스 문서·덱·이 데이터만으로 심의가 끝나도록 만든 교육용 데이터셋이다. 공시 수치와 교육용 가정은 모든 표에서 `is_assumed` 열(0 = 공시·의결·통계 수치, 1 = 교육용 가정)로 구분한다. 교육용 가정은 학생이 `w7m8_build.py` 상단 상수에서 바꾸어 판정 결과가 어떻게 달라지는지 확인하는 것이 실습의 일부다. 급여·보험료 현금흐름은 W06 케이스데이터(`fml_w6_cashflow.csv`)와 같은 가정을 써서 주차 간 숫자가 맞는다. 실습 덱이 쓰는 `fml_w8_liability.csv`(가상 DB 부채)와는 별개다.

## 실행 순서

```
python w7m8_build.py      # CSV 8개 생성 (현금흐름 추계 · 곡선 · 자산 · 시장 규모 · 안 · 시나리오 · 해외 비교 · 파라미터)
python w7m8_compute.py    # 조건 ①~⑤ 계산 → w7m8_results.json, compute_log.txt
```

필요 패키지: numpy, pandas. 국고채 곡선을 최신값으로 바꾸려면 `CURVE_OFFICIAL`(금융투자협회 최종호가 수익률 또는 한국은행 ECOS 817Y002)을 갱신한다. 기금 자산 구성은 기금운용본부 포트폴리오 현황(월별)에서, 국고채 만기별 발행·잔액은 재정경제부 국채시장 통계(`ktb.moef.go.kr` → 통계 → 국고채 종류별 발행액 및 잔액, 연도별 엑셀)에서 받는다.

## w7m8_compute.py 가 계산하는 것

- **부채**: 창 2026~2071(개혁 후 5.5% 공식 소진 연도) 순유출의 PV — 자체 5.5%(L_h)와 국채 곡선(L_g), ±100bp. 수정 듀레이션 D_L(±10bp 차분), 급여만의 D, DV01_L.
- **조건 ①**: FR_h · FR_g · 금리 −100bp 시 ΔFR_g ≤ −5%p → 갭 실재. 갭이 실재하면 부채 지표(LBP)가 없는 안(A)은 탈락. 참고: 수익률 5.5% vs 4.5%의 소진 연도.
- **자산**: 원화 DV01(국내채권 × D × 원화 노출), 헤지 비율 h0 = DV01_A/DV01_L, 갭 = D_A − D_L. 안 A·B의 출발점은 2027 SAA 목표 국내채권 21.8%를 벤치마크 듀레이션(5.5)으로 이행한 상태(h_SAA).
- **조건 ②**: 현물 매입 상한 = 30% × 5년 × 장기물 연 발행(87.3조) = 131조 · IRS 상한 = 5% × 연 거래(5,986조) = 299조. 안 B는 상한까지 30년물로 배정, 안 C는 목표 30%에 필요한 IRS 명목.
- **조건 ③**: 3영업일 +200bp 변동증거금 = ΔDV01 × 200, 버퍼 = ΔDV01 × 250 — 담보 적격 유동자산(단기자금 + 국고채) 이하인가.
- **조건 ④**: 헤지 후 μ ≥ 5.5%. 안 B는 SAA 안에서 4.2 채권을 30년물(4.60)로 바꾸므로 +0.03%p, 목표를 넘는 매입은 위험자산(8.0)에서 뺀다. IRS 캐리 = (고정 4.45 − KOFR 3.75) × 명목.
- **조건 ⑤**: 국내채권 비중 ≤ 21.8 + 7.0%p · IRS는 지침에 파생 조항이 없어 개정 전 불가.
- **격자·민감도**: 헤지 비율 5~100%에 필요한 현물 매입액·IRS 명목·증거금·μ, 조건 ② 임계(20·30·50%)와 기간(5·10년)에 따른 안 B의 헤지 비율.

결과는 `w7m8_results.json`(구조화)과 `compute_log.txt`(읽는 용)에 남는다.
