# W6 IC 케이스 데이터 사전 (기준일 2026-09-20)

케이스 문서·덱·이 데이터만으로 심의가 끝나도록 만든 교육용 데이터셋이다. 공시 수치와 교육용 가정은 모든 표에서 `is_assumed` 열(0 = 공시·의결·통계 수치, 1 = 교육용 가정)로 구분한다. 교육용 가정은 학생이 `w6_build.py` 상단 상수에서 바꾸어 판정 결과가 어떻게 달라지는지 확인하는 것이 실습의 일부다.

## 실행 순서

```
python w6_build.py      # CSV 8개 생성 (현금흐름 추계 · 글라이드패스 · KIC 모의 패널)
python w6_compute.py    # 제1호 조건 ①~⑤ · 제2호 조건 ①~③ 계산 → w6_results.json, compute_log.txt
```

필요 패키지: numpy, pandas. 실제 시계열로 제2호를 다시 돌리려면 아래처럼 받아 `fml_w6_kic_panel_sim.csv`와 같은 열 이름으로 넣는다(FRED 10년 금리 `DGS10`, 기대 인플레 `T10YIE`, `VIXCLS`; 자산은 ETF 프록시 TLT · TIP · URTH, 변동성 헤지는 VIXY).

```
import yfinance as yf, pandas_datareader.data as web
px = yf.download(["TLT","TIP","URTH","VIXY"], start="2011-01-01", interval="1mo")["Close"].pct_change()
st = web.DataReader(["DGS10","T10YIE","VIXCLS"], "fred", "2011-01-01").resample("ME").last()
```

## 파일과 열

### fml_w6_params.csv — 파라미터 (공시/가정 구분)

| 열 | 정의 |
|---|---|
| key | 파라미터 이름 (`hurdle_pct`, `hf_trigger`, `buffer_years`, `mu_risk` …) |
| value | 값 |
| meaning | 뜻 |
| is_assumed | 0 공시 · 1 교육용 가정 |

공시 값: 2025년 말 적립금 1,458.0조(국민연금 통계), 2025 재정추계(개혁 반영) 최대 적립 2053년 3,659조, 소진 2064년(수익률 4.5%) · 2071년(5.5%), 연금개혁 전제 기금수익률 5.5%, 기준포트폴리오 위험자산 65 : 안전자산 35, 위험한도 CVaR95 −15%, 보험료율 2026년 9.5%부터 매년 0.5%p 인상해 2033년 13%.

### fml_w6_fund_history.csv — 적립금 이력 (공시)

| 열 | 정의 | 단위 |
|---|---|---|
| year | 연도(2026.5 = 2026년 6월 말) | — |

### fml_w6_cashflow.csv — 연도별 현금흐름 추계 (교육용)

| 열 | 정의 | 단위 |
|---|---|---|
| year | 2026~2095 | — |
| contrib_rate_pct | 보험료율 | % |
| contrib_trn_krw | 보험료 수입 = 2026년 70조 × (1+임금상승 3%)(1−가입자 감소 0.8%)^k × 보험료율 비율 | 조 원 |
| benefit_trn_krw | 급여 지출 = 2026년 56조 × 증가율(~2050 7.50% · 2051~70 6.75% · 이후 3.5%) | 조 원 |

급여 증가율 두 개는 수익률 4.5%로 굴렸을 때 공시 정점(2053년·3,659조)과 소진(2064년)에 가장 가까워지도록 격자 탐색으로 맞춘 값이다(맞춘 결과: 정점 2050년 3,652조 · 소진 2065년). 실제 재정추계의 연도별 수입·지출은 공개 표가 아니므로 이 열 전체가 교육용 가정이다.

### fml_w6_cma.csv — 두 자산군 CMA (교육용)

| asset | name | mu_pct | sigma_pct |
|---|---|---|---|
| risk | 위험자산(주식+대체) | 8.0 | 15.0 |
| safe | 안전자산(채권) | 3.0 | 4.5 |

상관 0.10. 65:35 의 μ = 6.25%, σ = 10.0%. 허들 5.5%를 주는 최소 위험자산 비중 w_h = (5.5 − 3.0)/(8.0 − 3.0) = 50%.

### fml_w6_kic_panel_sim.csv — KIC 제2호 월간 모의 패널 (교육용, 480개월)

| 열 | 정의 | 단위 |
|---|---|---|
| date | 월말 | YYYY-MM-DD |
| yield10 · infl_exp · vix | 상태변수 — 10년 금리 · 기대 인플레이션 · 변동성 지수 | % · % · pt |
| bond_long_ret · tips_ret · eq_ret · vol_hedge_ret | 장기 국채 · 물가연동채 · 주식 · 변동성 헤지 월간 수익률 | 소수 |

설계: 금리는 반감기 약 10년으로 매우 지속적이고 금리 1%p가 이후 장기채 수익을 연 +1.0%p 예측한다(β ≈ 1). 기대 인플레 1%p는 물가연동채 수익 연 +0.6%p. VIX는 반감기 7개월로 빨리 되돌아가 장기 예측력이 없고, 변동성 헤지는 평시 캐리 −1.2%/월. 난수 시드는 `kic_panel_seed`(설계 범위 — 장기채 t 3~6, 물가연동채 t 2~3, VIX |t| < 1.2 — 에 드는 첫 시드)로 고정한다. 한 번의 40년 경로로도 장기 지평 회귀의 t값이 크게 흔들린다는 사실 자체가 질문 ②의 소재다.

## w6_compute.py 가 계산하는 것

- 제1호 조건 ① H/F(향후 30년 보험료 PV ÷ 기금)와 임계 0.625(총부 기준 위험자산 비중 40%) 도달 연도, 조건 ② 종점 비중 ≥ w_h, 조건 ③ 정점 이후 1σ 손실액 ÷ 급여 ≤ 1년치, 조건 ④ 소진 ≥ 2071, 조건 ⑤ 순유출 이후 안전자산 ≥ 급여 1.5년치. 참고 산수로 2008형 충격 1회(2027 · 순유출 전환 해 · 2050)가 소진을 앞당기는 연수와 안 B 의 속도·종점 민감도.
- 제2호 수단별 조건 ① 10년 지평 예측 회귀 t값(Newey–West) ≥ 2, 조건 ② 헤징 수요 (1 − 1/γ)·β·σ_x/σ_a ≥ 5%p, 조건 ③ 캐리 비용 ≤ 30bp. 참고로 장기채의 지평별(1·5·10년) t값과 γ 민감도.

결과는 `w6_results.json`(구조화)과 `compute_log.txt`(읽는 용)에 남는다.
