# W16 · 기말시험 · 캡스톤 최종 제출

강의는 없다. 16주차는 기말시험과 캡스톤 최종 제출로 비운다.

| 항목 | 내용 |
|---|---|
| 시점 | 16주차 |
| 범위 | **M10\~M16** — 9\~15주차에서 다룬 정규 모듈 7개 |
| 제외 | 특별세션 **SS1**(최적 통화 헤지) · **SS3**(세금 효율 투자)는 범위에서 뺀다 |
| 비중 | 기말시험 25% · 캡스톤 20% (발표는 15주차) |

## 캡스톤

주제는 **KFP TPA 전환 5년 로드맵**이다. 15주차에 발표하고 16주차에 최종본을 제출한다.
SS1 **환헤지 정책** · SS2 **리밸런싱 규정** · SS3 **DC 가입자 부록**이 권고안에
반영됐는지를 가점으로 평가한다.

배치의 근거는 [`_과정운영/16주_커리큘럼_배치표.md`](../_과정운영/16주_커리큘럼_배치표.md)에 있다.
