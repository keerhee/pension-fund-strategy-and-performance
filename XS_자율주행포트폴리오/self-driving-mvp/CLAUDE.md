# 자율주행 포트폴리오 MVP

Ang·Azimbayev·Kim(2026)의 에이전트 파이프라인을 이 강의 교재로 축소 구현한 것이다.

## 하네스

**트리거:** 자산배분·포트폴리오 구성·CMA·IC 표결 관련 작업 요청 시
`self-driving-portfolio` 스킬을 사용하라. 단순 질문은 직접 응답 가능.

- 에이전트 7개: `.claude/agents/`
- 스킬 5개: `.claude/skills/` — 각 에이전트의 작업 명세
- **정책: `ips.md`** — 이 파이프라인의 헌법이다. 행동을 바꾸려면 코드가 아니라
  이 문서를 고친다.

## 이 실습의 원칙

**사용자에게 터미널 명령을 시키지 않는다.** 환경 준비·데이터 수집·계산을 직접
처리하고 결과만 보고한다. 사용자는 프롬프트를 쓰고, 결과를 읽고, 무엇을 승인할지
판단한다.
