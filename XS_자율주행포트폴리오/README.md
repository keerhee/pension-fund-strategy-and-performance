# XS — 자율주행 포트폴리오

> **XS**(eXtra Session)는 특정 주차에 속하지 않는 독립세션이다. W06·W13·W14 안에 든
> 특별세션(SS1~SS3)과 달리 폴더가 따로 있고, 파일명 정렬에서도 W15 뒤에 온다.

Ang, A., Azimbayev, N., & Kim, A. (2026). *The Self Driving Portfolio: Agentic
Architecture for Institutional Asset Management* (arXiv:2604.02279)의 파이프라인을
**이 과정 16주 교재로 축소 구현한** 특별세션이다.

논문은 약 50개 에이전트가 자본시장 가정을 만들고 20가지 넘는 방법으로 포트폴리오를
구성해 서로 비평·표결하며, 메타 에이전트가 예측을 실현과 대조해 다른 에이전트의 코드와
프롬프트를 고쳐 쓰는 구조를 제시한다. 전체를 통제하는 것은 **투자정책서(IPS)** — 사람
운용역을 규율하던 바로 그 문서다.

## 구성

| 파일 | 내용 |
|---|---|
| `XS_자율주행포트폴리오_강의본.pdf` | 38장 — 논문 구조 · 교재 매핑 · harness · MVP 실습 · 한계 |
| `XS_케이스_자율파이프라인도입과규율_IC.pdf` | 19장 — 모의 투자위원회, 안건 2건 |
| `self-driving-mvp/` | 실제로 돌아가는 구현체 |
| `_build/` | 덱 생성 스크립트 (재빌드용) |

## 여섯 층과 우리 교재

| 층 | 하는 일 | 주차 |
|---|---|---|
| 거버넌스 | IPS가 전 과정을 제약 | W01 · W15 |
| 입력 | 자본시장 가정(CMA) | W03 |
| 구성 | 여러 방법이 경쟁 | W04(M4·M5) · W05 |
| 비평·투표 | 심사와 표결 | **16주 내내의 IC** |
| 탐색 | 새 방법 제안 | W12 · W13 (MVP에서는 생략) |
| 자기개선 | 예측 대 실현 대조 | W09 |

비평·투표 층이 이 세션의 열쇠다. **학생이 16주 동안 사람으로서 해온 IC가 논문에서
에이전트가 하는 일이다.** 새 이론을 배우는 세션이 아니라, 해온 일을 자동화하면 무엇이
남고 무엇이 사라지는지 확인하는 세션이다.

## MVP — 에이전트 7개

```
ips-guardian      거버넌스   IPS 해석과 위반 판정
cma-builder       입력       기대수익률·공분산 (W03)
alloc-mvo         구성       평균분산 최적화 (W04 M4)
alloc-bl          구성       블랙리터맨 (W04 M5)
alloc-riskparity  구성       위험기여 균등 (W05)
ic-critic         비평·투표   적격 심사와 네 관점 표결
meta-reviewer     자기개선   예측 대 실현 · 지시문 수정 제안 (W09)
```

구조는 [`revfactory/harness`](https://github.com/revfactory/harness)(황민호, Apache-2.0)로
세웠다. 도메인별 에이전트 팀을 설계하는 Claude Code 메타 스킬이며, 논문의 여섯 층과
개념이 1대 1로 대응한다 — 특히 harness의 Phase 7 "하네스 진화"가 논문의 메타 에이전트다.

## 실행 결과 (2026-08-22 · 본 강의 시뮬레이션)

자산 11개 · 학습 84개월 / 평가 35개월.

| 후보 | 유효N | IPS | 기대 | 실현 | MDD | 표결 |
|---|---|---|---|---|---|---|
| MVO (W04 M4) | 3.93 | **위반** | 5.93% | **8.58%** | -5.0% | 자동 기각 |
| 블랙리터맨 (W04 M5) | 5.53 | 적격 | 2.33% | 4.80% | -10.3% | 22.50 |
| 리스크 패리티 (W05) | 9.92 | 적격 | 5.25% | 7.43% | -7.6% | **35.96 채택** |

세 가지가 드러났다.

1. **MVO가 분산 요건(유효 종목 수 4.0)을 어겨 자동 기각됐다.** W04(M4)에서 가르치는 코너해가
   그대로 나왔고, 사람이 아니라 정책이 잡았다.
2. **그 기각된 안의 실현수익이 가장 높았다.** 규율을 지킨 대가가 1.15%p로 계산된다.
   이것이 IC 케이스의 안건이 된다.
3. **CMA는 크게 틀렸다** — 평균 절대오차 6.85%p, 금은 18.2%p. 그럼에도 성과가 나쁘지
   않았던 것은 예측이 맞아서가 아니라 제약이 분산을 강제했기 때문이다.

메타 에이전트는 지시문 수정 2건을 제안했고, IPS 7.4항(킬스위치)에 따라 **자동 반영되지
않았다**.

## 다시 돌리기 — 프롬프트 열 개

**터미널 명령을 치지 않는다.** Claude Code에서 이 폴더를 열고 순서대로 말하면 된다.

| # | 프롬프트 | 무엇이 생기는가 |
|---|---|---|
| P1 | 이 폴더에 실습 환경을 만들어줘. 파이썬 환경과 harness 설치까지 알아서 해줘 | 환경 · harness |
| P2 | 자율주행 포트폴리오 하네스를 구성해줘 (아래 전문) | 에이전트 7개 · 스킬 5개 |
| P3 | 우리 기금 투자정책서를 ips.md 로 써줘 (제약과 감독 조항 명시) | `ips.md` |
| P4 | 만든 에이전트들을 표로 보여줘 | 구조 이해 |
| P5 | cma-builder 를 실행해줘 | `cma.json` |
| P6 | alloc-mvo, alloc-bl, alloc-riskparity 를 모두 실행해줘 | `alloc_*.json` |
| P7 | ic-critic 으로 심사하고 표결해줘 | `ic_vote.json` |
| P8 | meta-reviewer 로 예측과 실현을 대조해줘 | `meta_review.json` |
| P9 | 사람이 판단해야 할 지점만 정리해줘 | 감독 대상 목록 |
| P10 | ips.md 의 유효 종목 수 하한을 3.5 로 낮추고 다시 돌려줘 | 정책의 효과 확인 |

P2의 전문은 이렇다. **이 한 문장이 팀 전체를 만든다.**

> 자율주행 포트폴리오 하네스를 구성해줘. ips.md 의 제약 안에서 자본시장 가정을
> 만들고, MVO·블랙리터맨·리스크패리티 세 방법으로 포트폴리오를 구성한 뒤,
> 투자위원회 관점에서 비평·표결하고, 과거 예측과 실현 수익률을 대조해
> 지시문 수정을 제안하는 팀이 필요해.

역할을 나누고(세 방법·비평·대조), 순서를 말하고("~한 뒤", "마지막에"), 제약의 출처를
지목한다("ips.md 의 제약 안에서"). 좋은 메타프롬프트의 세 조건이 한 문장에 들어 있다.

## 폴더 안에 무엇이 있나

```
.claude/agents/     에이전트 7개 — 역할·원칙·입출력·에러·협업
.claude/skills/     스킬 5개 — 각 에이전트가 어떻게 일하는지의 명세
ips.md              정책. 행동을 바꾸려면 코드가 아니라 이 문서를 고친다
runs/{날짜}/         한 사이클의 산출물 6개
_reference/         참조 구현. 학생은 볼 필요가 없다 — Claude Code가 쓴다
```

계산 절차는 스킬 문서에 적혀 있고, Claude Code가 그것을 읽고 `_reference/`의 구현을
호출한다. 그래서 누가 돌려도 같은 숫자가 나온다.

## 정책을 바꾸면 (P10)

`ips.md`의 유효 종목 수 하한만 4.0 → 3.5로 낮추고 다시 돌린 결과다.

| 후보 | 4.0 기준 | 3.5 기준 |
|---|---|---|
| alloc-mvo | 기각 | **26.04** (적격이 됐다) |
| alloc-bl | 22.50 | 22.50 |
| alloc-riskparity | **35.96 채택** | **35.96 채택** |

MVO는 표결에 올랐지만 이기지 못했다. 목표달성은 9.1로 가장 높았으나 분산 4.9 ·
집중도 2.0에서 밀렸다. **규칙을 완화해도 이번 결론은 바뀌지 않았다** — 이 사실이
IC 케이스 제2호 안건의 출발점이다.

## 한계

CFA Institute는 이 구조에 다섯 가지를 지적했다(*Self-Driving Portfolio: Promise and
Pitfalls*, 2026): 연쇄 오류, 거짓 합의, 자기개선의 역설, 감사 가능성, 국면 민감성.
MVP는 앞의 넷에 부분적으로 대응했고 **마지막 하나는 대응하지 못했다** — 금 예측이
18.2%p 빗나간 것이 그 증거다.
