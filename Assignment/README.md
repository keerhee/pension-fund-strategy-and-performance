# 과제 (Assignment)

주차별 팀 발표 과제. 각 과제 폴더의 `1_Student/`에 과제 안내·팀별 과제 PDF와 실습 데이터(`Data/`)가 있다.

| 폴더 | 내용 |
|---|---|
| `W06_Team_Assignment/` | W06 LDI·GBI 팀 과제 — 1팀 국민연금 금리 인하 · 2팀 금리 인상 · 3팀 H대학 기금 · 4팀 디폴트옵션 |
| `W07_Team_Assignment/` | W07 동적 포트폴리오 팀 과제 — 1팀 글라이드패스 · 2팀 KIC 헤징 · 3팀 국민연금 리밸런싱 · 4팀 기관 리밸런싱 규칙 |
| `W07_Team_Assignment_Bonus/` | W07 보너스(확장) 과제 — A 국면 TDF · B RL 검증 · C 역강화학습 · D 실데이터 헤징 |
| `W02_Lab_CAPM_GRS/` | W02 개인 실습 — CAPM 시계열 회귀와 GRS 검정 (산업 30 · 모멘텀 10 · 규모×BE/ME 25) |
| `W10_Lab_Factor_Models/` | W10 개인 실습 — SMB·HML·UMD 직접 구성, CAPM→FF3→4팩터 GRS, 위탁운용사 알파 재측정 |
| `W12_Team_Project_Factor_Adoption/` | W12 팀 프로젝트 — 국내주식 팩터 도입: 1팀 가치 · 2팀 모멘텀 · 3팀 규모 · 4팀 결합 (미국 90년 + JKP 표본 밖·한국 검증) |
| `BAF634_Factor_Data/` | 위 세 과제의 공용 데이터와 계산 도구 `factor_lab.py` — KAIST BAF634(2025) `Problem_Set_2.xls` 기반 |

먼저 각 폴더의 `*_Guide.pdf`(전체 가이드)를 읽고, 계산 도구는 `Data/` 아래 팀 폴더에서 `python3 <도구>.py`로 실행한다. W02·W10·W12 과제는 `BAF634_Factor_Data/` 의 `factor_lab.py` 하나를 함께 쓴다.
