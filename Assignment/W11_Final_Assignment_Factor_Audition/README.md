# W11 파이널 과제 — 팩터 오디션 (Easy version)

기금의 해외주식 팩터 슬리브(10조 원)에 넣을 팩터를 153개 후보 가운데 최대 10개 고른다. 판정은 Claude Code가 하고, 수강생은 지시문 5개를 붙여넣은 뒤 결과를 확인하고 IC 안건서를 결재한다. 단순 t값 기준과 JKP(2023) 계층 베이지안 기준(군집 13개로 보정)을 비교하고, 2010년 오디션 → 이후 10년 채점, Value 겨울 드로다운 규칙을 시험한다.

| 파일 | 내용 |
|---|---|
| `1_Student/Factor_Audition_Lab_Easy.pdf` | 과제지 (준비 → 기본 지식 4가지 → 5단계 실습 → 판단 문제 → 제출물과 채점). 원본 `.md`·`.docx` 함께 |
| `1_Student/Factor_Audition_Lab_Deck_Easy_II.pdf` | Easy판 과제 설명 덱 19장 (준비·5단계) (편집 원본 `.pptx`는 저장소 제외) |

| `1_Student/Videos/Factor_Audition_Lecture_Motion.mp4` | 과제 소개 모션 영상 2분 35초 (저장소 제외) |
