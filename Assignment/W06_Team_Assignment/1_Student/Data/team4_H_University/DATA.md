# H대학교 발전기금 데이터 (4팀)

H대학교는 가상 기관이다. 기금 규모 · 지출 · 공사비 · 인력은 모두 교육용 가정이다.

| 파일 | 내용 |
|---|---|
| hu_params.csv | 기금 5,000억, 현행 지출 200억, 공사비 600억, 출자 요청 규칙, 판정 기준 임계값, 인력 요건 |
| hu_cma.csv | 자산군별 기대수익 · 변동성 (교육용 가정) — 주식 · 국채 · 현금 · 사모투자(재간접) · 사모투자(직접) |
| hu_scenarios.csv | 충격 시나리오 — 2022형(주식 −20%, 국채 −15%), 2008형(주식 −40%, 국채 +8%) |
| hu_spend_cashflow.csv | 30년 연도별 고정 지출(3.5%) · 현행 지출(4.0%, 물가 2% 상승) |
| hu_panel_sim.csv | 40년(480개월) 월별 모의 수익률 패널(교육용 생성 데이터)(주식 · 국채 · 현금 · 사모투자 · 물가). 30년 모의실험의 재료 |

계산 도구 `h_univ_tool.py` 옵션: `--eq --bond --cash --alt`(비중 %, 합계 100) · `--z`(지출률 %) · `--lump-year`(공사비 인출 연차) · `--staff`(전담 인력). 옵션 없이 실행하면 A · B · C 세 안을 비교한다.
