# 퇴직연금 디폴트옵션 데이터 (4팀)

| 파일 | 내용 |
|---|---|
| do_params.csv | 가입자(55세 → 65세), 안전 목표 1.10, 채권 금리 출발값 3.0%, 원리금보장 수익률 3.09% |
| do_public_facts.csv | 국내 퇴직연금 · 디폴트옵션 · TDF 시장 현황과 해외 기금 참고 수치 (공시 자료, 출처 열 참고) |
| do_panel_sim.csv | 40년(480개월) 월별 모의 수익률 패널(교육용 생성 데이터)(주식 수익률 · 10년 금리 등). 4,000개 경로 모의실험의 재료 |

계산 도구 `default_option_tool.py` 옵션: `--rate`(10년 채권 금리 %) · `--guar`(원리금보장 수익률 %) · `--cppi X M FEE`(임의의 CPPI) · `--tdf W FEE`(임의의 혼합형). 옵션 없이 실행하면 금리 3.0%에서 A · B · C 세 상품을 비교한다.

모의실험: 주식 수익률은 패널에서 12개월 단위로 다시 뽑고, 채권 금리는 출발 금리 주변에서 움직인다. CPPI는 3개월마다 주식 비중을 다시 맞춘다. 위기 첫해 시나리오는 첫 12개월을 2022형(주식 약 −20%, 금리 +3%p)으로 고정한다.
