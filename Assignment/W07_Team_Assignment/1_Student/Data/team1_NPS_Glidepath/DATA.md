# 국민연금 글라이드패스 데이터 (1팀)

| 파일 | 내용 | 출처 |
|---|---|---|
| gp_cashflow.csv | 2026~2095년 연도별 보험료율 · 보험료 수입 · 급여 지출(조 원) | 교육용 추계 — 2025 재정추계의 최대 적립(2053년 3,659조) · 소진(2064년, 수익률 4.5%)에 맞춘 가정. 보험료율은 2026년 9.5%부터 매년 0.5%p 올라 2033년 13% |
| gp_glidepaths.csv | 세 안의 연도별 위험자산 비중 (A 65% 고정 · B 2042년부터 연 1%p 감축해 50% · C 2027년부터 연 1%p 감축해 45%) | 교육용 설계 |
| gp_cma.csv | 위험자산 · 안전자산의 기대수익 · 변동성 (8.0% · 15.0% / 3.0% · 4.5%) | 교육용 가정 |
| gp_scenarios.csv | 위기 충격 — 2022형(위험 −9.4% · 안전 −5.0%), 2008형(위험 −22% · 안전 +4%) | 교육용 가정 |
| gp_fund_history.csv | 적립금 이력 (2023 · 2024 · 2025 · 2026.6) | 보건복지부 · 국민연금 통계 |
| gp_params.csv | 적립금, 재정추계 공식 수치, 허들, 판정 기준 임계값, 인적자본 할인율 등 | 공시 + 교육용 가정 |

계산 도구 `glidepath_tool.py` 옵션: `--start`(감축 시작 연도) · `--speed`(연 감축 %p) · `--floor`(종점 위험자산 %). 옵션 없이 실행하면 세 안을 비교한다.

판정 기준과 출처 (모두 옵션으로 바꿀 수 있다)

| 기준 | 기본값 | 출처 | 옵션 |
|---|---|---|---|
| ① 감축 시작 임계 H/F | 0.65 ÷ 0.40 − 1 = 0.625 | 교육용 — 총자산(F+H) 기준 목표 위험 비중 40% | `--tw-target` |
| ② 허들 | 5.5% | 공시 — 2025 연금개혁 전제 기금수익률 | `--hurdle` |
| ③ 1σ 손실 ÷ 급여 | ≤ 1년치 | 교육용 | `--loss-max` |
| ④ 소진 | ≥ 2071년 | 공시 — 2025 재정추계(수익률 5.5%) | `--deplete-min` |
| ⑤ 안전자산 ÷ 급여 | ≥ 1.5년치 | 교육용 | `--buffer` |
| 자본시장 가정 | 위험 8.0%/15.0% | 교육용 | `--mu-risk` · `--sig-risk` |
단순화: 기금은 매년 기대수익으로 굴리고, 위기 충격은 한 해에만 넣는다. 국민연금의 실제 운용 계획이 아니다.
