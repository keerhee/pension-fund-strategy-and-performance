# 보너스 C — 데이터와 가정

## 파일
| 파일 | 내용 |
|---|---|
| `committee_decisions.csv` | **교육용 모의 자료** 180개월. month · exp_excess_ret(이번 달 기대초과수익, 연율) · drawdown_state(손실 국면 1/0: 시장이 고점 대비 −15% 이하) · prev_weight(전월 비중) · weight(위원회 결정) · realized_excess_ret(그 달 실제 주식 초과수익) |
| `irl_tool.py` | 최대 엔트로피 IRL(조건부 로짓 최우추정) · 항을 뺀 추정 · 세 안의 미래 10년 성과 · 판정표. 자료 생성 과정은 `make_data()`에 공개(`--make-data`로 다시 만든다) |

## 가정
| 항목 | 값 | 옵션 |
|---|---|---|
| 행동 | 주식 비중 20~70%, 5%p 간격(11개) | |
| 시장 | 기대초과수익 = 5% + 3% × 밸류에이션 신호(월 자기상관 0.95), 주식 변동성 16% | |
| IPS 위험회피 | γ = 4 | |
| 보상 구조 | u = a·μ − (γ/2)σ²a² − κ(a − 전월)² − δ·손실 국면·a, 선택 확률 ∝ exp(u/τ) | |
| 추정 자료 기간 | 최근 15년 | `--years` |
| 미래 평가 | 10년 × 2,000개 경로, 매매 비용 편도 10bp | `--cost` |
| 판정 기준(교육용) | ① \|t\| ≥ 2 · ② 두 관점 모두 현행 대비 개선 · ③ 불리한 관점의 후회 ≤ 15bp/년 | `--t-min` `--regret-max` |
