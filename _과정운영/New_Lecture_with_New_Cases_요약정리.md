## 2. IC 운영 매뉴얼 — 모든 케이스의 공통 규칙

### 2.1 위원회의 헌법 세 문장

1. 정답이 아니라 논증을 평가한다 — A·B·C 어느 안도 정답이 아니고, 점수는 근거의 품질·반대심문 방어·직무 언어의 일관성으로만 매긴다.
2. 모든 발언에는 숫자 하나·출처 하나 — 근거 없는 형용사("좋습니다", "위험합니다")는 발언으로 치지 않는다.
3. 승패가 아니라 의결문이 남는다 — 산출물은 표결 결과가 아니라 조건이 담긴 의결문 한 장이며, 그것이 팀 과제와 캡스톤의 1페이지가 된다.

### 2.2 20인 배분

| 구성 | 인원 | 임무 |
|---|---|---|
| 위원장 | 1 | 진행·시간 통제·콜드콜 (교수가 아니라 학생이 마이크를 잡는다) |
| 독립심사위원 | 3 | 반대심문 전담 · 발언 체크리스트 · 루브릭 채점 보조 |
| 운용전략(CIO)팀 | 4 | 권고안 설계 — 배분·이행 속도·실행 계획 |
| 리스크관리팀 | 4 | 위험·유동성 검증, 과대 추정 감시 |
| 재정·거버넌스팀 | 4 | 비용·국민 설명 — "왜 하는가"의 방어 |
| 글로벌자문팀 | 4 | 해외 벤치마크 매핑 — 모방 가능성 진단 |

간사는 AI가 맡는다(기록은 AI, 책임은 사람). 교수는 위원장 뒤의 감사로 물러나 강평만 담당한다.

### 2.3 60분 시간표

| 시간 | 세션 |
|---|---|
| 0–10분 | 브리핑 — 안건서·심의 자료 요약 |
| 10–25분 | 팀 준비 — 발언 요지 1장 완성 |
| 25–41분 | 팀 발표 4팀 × 4분 (30초 초과 시 마이크 회수) |
| 41–53분 | 반대심문 — 심사위원 질문 후 교차질문, 답변 60초 |
| 53–60분 | 표결·확정·강평 — 전원 표결, 기권 불가 |

좌석은 ㄷ자 배치. 위원장·심사위원이 열린 면, 4팀이 양 날개에 마주 앉는다.

### 2.4 산출물과 평가

산출물 세 장: **발언 요지 1장**(팀별, 준비 15분) · **의결문**(AI 초안, 위원장 확정) · **소수의견서**(반대자의 권리, 우수 시 가산).

평가는 팀 80점 + 개인 20점.

| 구분 | 축 | 만점 기준 |
|---|---|---|
| 팀 80 | 기여·보정 언어 16 | 수익률 언어 0회 — 보정·조건의 언어로 일관 |
| | 숫자 근거 16 | 모든 주장에 출처, 과대 추정 0회 |
| | 설계 구체성 16 | 권고안이 의결문 수준(배분·속도·하한) |
| | 반대심문 방어 16 | 즉답 — 회피·동문서답 감점 |
| | 팀 정체성 16 | 자기 직무의 언어와 이해관계 유지 |
| 개인 20 | 발언 체크 10 + 역할 수행 10 | 심사위원 체크리스트 + 역할별 의무 |

## 3. 주차별 내용 요약

### 3.1 Week 10 — 위험관리와 성과평가

3교시 구성: 위험 척도 → 성과 지표 → 귀인·현실.

- **1교시** — 위험의 네 정의(σ·VaR·CVaR·MDD), Artzner(1999)의 Coherent 공리, VaR의 부분가법성 위반 반례, VaR 추정 3법과 스트레스 테스트, MDD·Calmar.
- **2교시** — Sharpe·Sortino·IR·Treynor·Jensen α의 분자·분모·용도 비교, 같은 포트폴리오가 지표에 따라 갈리는 실험, Grinold 기본법칙 $\mathrm{IR} = \mathrm{IC}\sqrt{\mathrm{BR}}$과 그 세 한계.
- **3교시** — Brinson(1986) 배분·선택·교차 귀인과 초과수익 +3.2%p 분해, FLAM 팩터 통합, 자산군 분산 뒤에 숨은 팩터 집중, SPIVA, KIC의 2022\~2025 궤적.
- **에피소드** — LTCM의 VaR 신화 붕괴(1998), Artzner 혁명, Grinold(1989), SPIVA 충격, 한국 기관 평가체계의 진화.
- **케이스 2건** — ① 국부펀드 2022년 −8.6%(복합 BM −9.2%) 평가 ② 대체투자 PME 채택과 3페르소나 지표 매트릭스.

### 3.2 Week 11 — 주식 퀀트 모델

- **1교시** — 퀀트 4단계 파이프라인(Alpha · Risk · Portfolio · Execution), 단계별 IC, 팩터 기반 공분산, 비용을 아는 최적화, Implementation Shortfall, Net IR 분해.
- **2교시** — Fama-French 3요인부터 FF5·Q-Factor까지 60년, 버핏 알파 해부(멀티 팩터 노출 + 레버리지 + 인내로 대부분 설명, 알파는 거의 0), JKP(2023) 복제 위기 — 82%가 복제되고 13개 테마로 압축.
- **3교시** — 페어 트레이딩(공적분·평균회귀), 퀀터멘털, 메타 레이블링 4단계 구현과 효과·한계, 백테스트 5함정, PSR·Deflated Sharpe.
- **케이스 2건** — ① 액티브 주식 운용의 기로(NPS 국내주식 +82.44%의 대부분이 β였다) ② 메타 레이블링 도입 여부.

### 인용 정정 — 슬라이드 31 Carry 실증

기존 인용 Ilmanen-Maloney-Ross (2014)는 두 가지가 맞지 않았다. 2014년 논문에

Value·Momentum·Carry·Defensive 네 팩터를 글로벌 국채를 포함한 자산군에서
2020년까지 검증한 AQR 계열 논문으로 바꿨다.

| 항목 | 수정 전 | 수정 후 |
|---|---|---|

### 수치 정정 — PIMCO vs Dimensional 2022 (슬라이드 32·40)

"둘 다 졌다"의 비교 기준이 슬라이드에 없어 검증이 불가능했다. 기준을

두 펀드의 2022년 실제 수익률로 맞췄다. 둘 다 Morningstar 분류상 인터미디엇

| 슬라이드 | 항목 | 수정 전 | 수정 후 |
