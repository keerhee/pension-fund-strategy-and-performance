# 실습 데이터 가이드 (W01–W15)

각 주차 실습이 **어떤 데이터를 필요로 하고, 그것을 어디서 어떻게 구하는지**를
한 덱에 정리했다. 덱과 생성 데이터는 모두 해당 주차 폴더에 강의본·케이스와 함께
들어 있다 — 예를 들어 `W07_LDI와GBI/`에는 강의본, 케이스, 실습데이터 덱
(`W07_M8_실습데이터_LDI부채연계투자.pdf`), 부채 현금흐름(`fml_w8_liability.csv`)이
같이 있다. 구성은 모든 주차가 같다.

| 장 | 내용 |
|---|---|
| 1 | 표지 |
| 2 | **문제** — 실습 산출물과 답해야 할 질문 |
| 3 | **필요한 데이터** — 항목·형식·단위 명세 (= CSV 열 정의) |
| 4 | 명세에 드러나지 않는 함정과 데이터 설계의 원칙 |
| 5 | **데이터 출처** — 출처·형식·공개 여부 |
| 6 | 그 데이터를 어떻게 다룰 것인가 (공개/가상 판단) |
| 7 | **Claude Code** — 수집 프롬프트와 작성 요령 |
| 8 | 다음에 무엇을 시킬 것인가 · 이후 주차 재사용 |
| 9 | **검증** — 맞춰볼 것과 자주 나오는 오류 |

본문은 18pt, 코드는 16pt로 짰다. 강의실 뒷자리에서도 읽히도록 원 강의본의
20pt 규칙에 맞춘 것이다. 패널 높이와 표의 행 높이·열 폭은 글자 수에서 역산해
자동으로 잡히므로, 내용을 고쳐도 글자가 넘치거나 행이 겹치지 않는다.

## 가상 데이터를 쓰는 주차

네 주차는 데이터가 원천적으로 공개되지 않는다. 생성본은 해당 주차 폴더에 넣어 두었다.

| 파일 | 주차 폴더 | 무엇 | 왜 가상인가 |
|---|---|---|---|
| `fml_w8_liability.csv` | W07 | 부채 현금흐름 50년 | 가입자별 지급 스케줄은 계리 자산이자 개인정보다 |
| `fml_w9_person.csv` · `fml_w9_goals.csv` | W07 | 이순자 씨 프로필·목표 | 개인 재무 자료는 강의 자료가 될 수 없다 |
| `fml_w12_bonds.csv` · `fml_w12_cb.csv` | W11 | 채권 종목 명세 | 국내 회사채는 장외라 호가가 공개되지 않는다 |
| `fml_w15_pe_cashflow.csv` | W14 | PE 펀드 현금흐름 | Preqin·Burgiss는 유료이고 LP 계약상 제한된다 |
| `fml_w16_kfp.csv` | W15 | 가상 기금 KFP | 부서별 성과·팩터 노출은 어느 기금도 공개하지 않는다 |

**생성 데이터도 시장과 정합하게 만들었다.** 채권 가격은 실제 커브로 산출하고, PME의
분모는 실제 공모지수를 쓰며, KFP의 자산군 수익률은 실제 시장 국면(2022년 동반 하락)을
따른다. 지어낸 것은 구조와 규모이지 시장 자체가 아니다.

생성 데이터가 실제와 닮았는지는 다음 기준으로 확인했다.

- 부채 — 수정듀레이션 **18.0년** (DB 연기금 통상 15~20년), 지급 정점 t=30의 종 모양
- PE — TVPI 중앙값 **1.90**, 21개 펀드 전부 초기 3년 순현금 음(−) = J-커브,
  NAV 자기상관 **+0.54** (평활화 실습의 전제)
- KFP — 분기 비중합 96~105%, 2021 +2.8% / 2022 −2.5%로 동반 하락 재현

## 사용 규칙

1. 가상 데이터를 쓴 발언은 IC에서 **"강의 제공 가상 데이터 기준"**이라고 밝힌다.
2. 공개 데이터는 실습 시점의 최신 수치로 갱신한다 — 덱의 표는 작성 시점 기준이다.
3. 각 주차에서 만든 CSV는 지우지 않는다. 뒤 주차가 앞 주차 산출물을 재사용한다.
   (W02 패널 → W04 공분산 → W04 BL → W05 ERC/HRP → W09 성과평가 → W15 TPA)
   앞 주차 폴더에서 파일을 찾게 되므로 작업 폴더를 옮길 때 함께 옮긴다.
