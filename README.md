# 연기금 운용전략과 성과평가

BAF.60080 · 2026 가을학기 · 강의본 · 모의 투자위원회(IC) 케이스 · 특별세션

**16주 전 과정**의 강의 덱과 케이스 덱을 주차별로 묶었다.
설계 원리는 하나다 — **강의는 케이스를 위해 존재하고, 케이스는 표결이 아니라 의결문을 남긴다.**
매주 3교시(180분) 이론을 진행하고, 4교시(60분)에 그 주의 개념으로 모의 투자위원회를 연다.

덱 56개 · 슬라이드 1,711장. **이 저장소에는 PDF와 마크다운만 올린다** — 편집 원본인 PPTX는
`.gitignore`로 제외한다(바이너리라 수정할 때마다 히스토리에 통째로 쌓인다).

## 폴더 구조

주차 폴더 하나에 그 주의 강의본·케이스·보강이 모두 들어 있다.

```
W01_시장개요와자산소유자/ … W16_TPA/    주차별 덱 (PDF)
_과정운영/                              실라부스 · IC 매뉴얼 · 요약정리 · 권리 감사
_참고자료/                              외부 원전 안내
LICENSE · README.md
```

특별세션(SS)은 선수 모듈이 있는 주차에 함께 넣었다 — **SS2는 W07**(동적 배분 직후),
**SS1은 W14**(매크로·통화 직후), **SS3은 W15**(대체투자와 함께).

각 PDF의 쪽수는 원본 슬라이드 수와 1:1로 일치한다. GitHub는 PDF를 브라우저에서 바로
렌더하므로 클론 없이 읽을 수 있다. 편집이 필요하면 PPTX 원본을 별도로 요청한다.

## 모의 투자위원회(IC) 운영

20인 위원회 — 4팀 16명 + 운영진 4명(위원장 1, 독립심사위원 3). 간사는 AI가 맡는다.

| 시간 | 세션 |
|---|---|
| 0–10분 | 브리핑 |
| 10–25분 | 팀 준비 — 발언 요지 1장 |
| 25–41분 | 팀 발표 4팀 × 4분 |
| 41–53분 | 반대심문 |
| 53–60분 | 표결 · 확정 · 강평 |

산출물은 세 장이다 — **발언 요지 · 의결문 · 소수의견서.** 평가는 팀 80점 + 개인 20점이며,
정답이 아니라 논증의 품질로 매긴다. 자세한 규칙은
[`_과정운영/IC운영매뉴얼_모의투자위원회_20인.pdf`](_%EA%B3%BC%EC%A0%95%EC%9A%B4%EC%98%81/IC%EC%9A%B4%EC%98%81%EB%A7%A4%EB%89%B4%EC%96%BC_%EB%AA%A8%EC%9D%98%ED%88%AC%EC%9E%90%EC%9C%84%EC%9B%90%ED%9A%8C_20%EC%9D%B8.pdf)에 있다.

## 자료에 관한 주의

- **가상 기관** — 국부펀드 K와 미래연금(KFP)은 실재하지 않는다. 다만 규모·제약은
  한국 공적 기금의 전형을 따랐다.
- **실명 기관의 수치** — NPS·KIC·CPPIB 등의 숫자는 공개 자료에 기반한 추정이며,
  판단의 틀을 익히는 것이 목적이다. 투자 판단의 근거로 쓸 수 없다.
- **정본 정책** — 같은 안건의 판본이 여럿이던 파일은 하나로 정리했다. 수치를 고칠 때는
  출처를 확인한 뒤 반영하고, 이력을
  [`_과정운영/New_Lecture_with_New_Cases_요약정리.md`](_과정운영/New_Lecture_with_New_Cases_요약정리.md) 5절에 남긴다.
- **오류 신고** — 수치나 인용에 잘못이 보이면 이슈로 알려주면 고친다. 지금까지 확인된
  정정 이력도 위 문서에 남아 있다.
